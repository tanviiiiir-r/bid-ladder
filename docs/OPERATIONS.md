# Bid Ladder — Operating Procedures

## CEO Activation

1. Read COMPANY.md, ROADMAP.md, DECISIONS.md.
2. Inspect GitHub state.
3. Produce recommendation in OBSERVATION/EVIDENCE/IMPACT/RECOMMENDATION/PRIORITY/SCOPE/CONFIDENCE format.
4. Wait for founder approval on major decisions.

## Decision Protocol

- Major strategic, financial, destructive → Founder approval + DECISIONS.md.
- Product/technical direction → CEO proposes, founder approves.
- Routine documentation/organization → CEO may execute.

## Communication

- Founder receives: status, decisions, blockers, risks, recommendations, metrics, approval requests.
- No implementation noise unless it creates risk.
