# Decision template

Append a filled block to `DECISIONS.md`. Also add a row to the index table. Do not mark `DECIDED` unless the founder has approved.

```text
ID: DECISION-XXX
Date: YYYY-MM-DD
Topic:
Decision:
Rationale:
Status: DECIDED / PROPOSED / OPEN
Approver:
```

## Rules

- Do not fabricate decisions.
- MAJOR strategic, financial, or destructive changes require founder approval and an ID.
- Economic values stay hypotheses until an experiment and a DECIDED row say otherwise.
- PROPOSED means the text is a recommendation. Treat it as not binding.
- When status changes, update both the block and the index table in `DECISIONS.md`.
